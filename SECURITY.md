# Security Policy

The Mergington High activities website may handle student information, so please report security problems privately rather than through a public issue.

## Reporting a vulnerability

Use the **Security** tab's **Report a vulnerability** option if private vulnerability reporting is enabled. Otherwise, contact the repository owner privately before sharing any technical details. Don't post student data, credentials, or working exploits in public discussions.

Please include a short description, steps to reproduce with test data, and the potential impact. We'll work to acknowledge reports within two school days and prioritize anything that could expose private student information.

Thanks for helping keep the site safe.
