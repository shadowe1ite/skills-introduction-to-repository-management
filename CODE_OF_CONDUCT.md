# Code of Conduct

We want this project to be a welcoming place for everyone helping with Mergington High's extracurricular activities website.

## What we expect

Be respectful, assume good intentions, welcome questions, and give feedback about the work rather than the person. Please take extra care when discussing student-related features or information.

Harassment, personal attacks, discriminatory remarks, sharing someone's private information, or threatening behavior aren't acceptable.

## Handling concerns

If an interaction makes you uncomfortable, contact the school's IT Club faculty advisor privately. Maintainers will review reports fairly, keep details limited to those who need to know, and may remove harmful comments or contributions.

These expectations apply to repository issues, pull requests, discussions, and other project spaces.
