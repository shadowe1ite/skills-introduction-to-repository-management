# Contributing to Mergington High Activities

Thanks for helping keep the clubs website useful for students and teachers. Small fixes, clearer instructions, and ideas for new activities are all welcome.

## Getting started

1. Clone this repository and create a branch for your change.
2. Install dependencies with `pip install -r requirements.txt`.
3. Start the site with `python src/app.py` and open http://localhost:8000.
4. Test your change with sample data, not real student information.

## Sending a change

- Check the existing issues before starting a larger feature.
- Keep each pull request focused on one bug or improvement.
- Describe what changed, why, and how you tested it.
- Ask for a review before merging. Please don't commit credentials or student records.

## Style and questions

Use clear names and follow PEP 8 for Python. If you're stuck, open an issue explaining what you tried. It's always better to ask early than guess.
